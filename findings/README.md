# Historical advisory audits

- [Fable audit, October 22, 2026](2026-10-22-fable-audit.md)
- [Astra addendum, October 23, 2026](2026-10-23-astra-addendum.md)

These are preserved static-review reports against the captured source revision
and snapshot identified inside them. Their findings are investigation leads,
not verified defects in today's code. Suggested fixes and source-line citations
need to be checked against the current implementation before acting on them.
No historical audit was rerun as part of archiving these files.

The Fable file already includes the Astra addendum after its original report.
The separate addendum is retained because it was independently supplied; the
duplication is intentional. Both original files are byte-preserved.

`source/` citations and references to `AUDIT-SCOPE.json` refer to the original
external audit snapshot, which is not included here. Historical task/run IDs
likewise do not imply that their complete runtime artifacts are in this checkout.

See the [research archive index](../Insights/README.md) for the earlier evidence
and the [handoff implementation report](../docs/handoff-implementation.md) for
the later implementation and known limitations.
